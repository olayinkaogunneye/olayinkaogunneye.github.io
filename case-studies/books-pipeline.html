Project Overview

The BooksToScrape Data Engineering Pipeline is a full end‑to‑end project demonstrating modern data engineering practices. It includes automated scraping, medallion‑style transformation, and analytics‑ready datasets for downstream reporting.

Problem

The BooksToScrape website contains valuable product information, but:

  • No API exists for structured extraction
  • Categories must be discovered dynamically
  • Data quality varies across pages
  • Manual scraping is slow and inconsistent

A scalable, automated pipeline was needed to ingest, clean, and model the data.

Solution

I engineered a complete pipeline with:

  • Automated category discovery
  • Python web scraping using BeautifulSoup
  • DuckDB + MotherDuck storage
  • dbt transformations and tests
  • Medallion architecture modeling

The result is a clean, scalable, and analytics‑ready dataset.

Architecture

The pipeline follows the Medallion Architecture:

  • Bronze Layer — Raw scraped HTML converted into structured tables
  • Silver Layer — Cleaned, validated, enriched book and category datasets
  • Gold Layer — Business‑ready models for pricing, ratings, and category insights

Tools used:

  • Python (BeautifulSoup, Requests)
  • DuckDB / MotherDuck
  • dbt
  • Jupyter

Impact

  • Automated scraping across all categories
  • 100% reproducible ingestion pipeline
  • Clean, validated datasets
  • Analytics‑ready gold models

Outcome

The BooksToScrape Pipeline provides:

  • A fully automated scraping workflow
  • Structured datasets for analysis
  • Scalable medallion architecture
  • Reliable gold‑layer insights
