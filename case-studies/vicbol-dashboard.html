Project Overview

VicBol Performance Analytics is a complete Power BI project analyzing marketing performance across spend, traffic, and revenue. The dashboard provides executives with a unified view of channel effectiveness, ROI, and customer engagement trends.

Problem

VicBol’s marketing data was siloed across multiple sources, making it difficult to:

  • Understand which channels drive the most revenue
  • Track spend efficiency and ROI
  • Analyze traffic patterns over time
  • Provide executives with a unified performance dashboard

Reporting was inconsistent and lacked a single source of truth.

Solution

I engineered a complete Power BI solution with:

  • Power Query for ingestion and transformation
  • A star-schema data model for marketing analytics
  • DAX measures for spend, traffic, revenue, and ROI
  • Interactive visuals for channel performance

The dashboard provides a clear, unified view of marketing effectiveness.

Data Model & Architecture

The solution uses a star-schema model:

  • Fact Performance — Spend, traffic, and revenue metrics
  • Dim Channel — Marketing channels and classifications
  • Dim Date — Calendar and fiscal periods
  • Dim Region — Geographic segmentation

Tools used:

  • Power BI
  • Power Query
  • DAX
  • Excel / CSV source files

Impact

  • Unified view of marketing performance
  • Clear insights into channel ROI
  • Improved spend allocation decisions
  • Executive-ready reporting

Outcome

The VicBol Performance Analytics dashboard provides:

  • Actionable insights into marketing effectiveness
  • Reliable performance metrics across channels
  • Interactive visuals for deeper analysis
  • A scalable foundation for future BI enhancements
