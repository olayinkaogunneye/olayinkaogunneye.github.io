Project Overview

This project explores the evolution of Netflix content using a structured analytics workflow. The goal is to understand how Netflix’s catalog has changed over time across genres, countries, ratings, and release patterns.

Problem

Netflix’s global catalog is massive and constantly evolving. However:

  • Raw datasets contain duplicates and missing values
  • Country and genre fields are inconsistent
  • Release dates require normalization
  • Insights are difficult without structured modeling

A clean, analytics‑ready dataset was required to uncover meaningful trends.

Solution

I engineered a complete analytics workflow with:

  • Python data cleaning (Pandas)
  • DuckDB transformations
  • Feature engineering for genres and countries
  • Exploratory analysis notebooks
  • Power BI storytelling dashboards

The result is a clean dataset and a rich set of insights into Netflix’s content evolution.

Architecture

The workflow includes:

  • Data Cleaning — Handling nulls, duplicates, inconsistent formats
  • Transformation — Genre splitting, country normalization, date parsing
  • Modeling — Creating analytics‑ready tables
  • Exploration — Trend analysis using notebooks
  • Visualization — Power BI dashboards

Tools used:

  • Python (Pandas)
  • DuckDB
  • Jupyter
  • Power BI

Impact

  • Clean, structured dataset for analysis
  • Clear insights into genre and country trends
  • Improved understanding of Netflix’s global strategy
  • Interactive dashboards for storytelling

Outcome

The Netflix Content Analysis project provides:

  • A reliable dataset for trend analysis
  • Insights into global content distribution
  • Visual storytelling dashboards
  • A reusable analytics workflow
